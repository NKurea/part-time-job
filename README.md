# バイト管理（スマホ用 Web アプリ）

Googleカレンダーの予定からアルバイトを抽出し、**給与見込・労働時間**を月別／年間で表示します。
あわせて、千疋屋の**シフト希望提出（毎月5日・20日）**をリマインドします。

- ホーム画面に追加するとアプリとして使えます（PWA・オフライン表示対応）
- データはスマホ内（ブラウザ）にのみ保存され、外部サーバーには送信しません

## 機能

### ① 給与見込と労働時間
タイトルに「千疋屋」「学童」を含む時間指定の予定を集計します。「バイト」を含む予定は千疋屋として扱います（終日予定・「シフト希望」「リマインド」を含む予定は除外）。

| | 千疋屋 | 学童 |
|---|---|---|
| 時給 | 〜2026/8/31：1,300円<br>2026/9/1〜：1,350円 | 〜2026/9/30：1,270円<br>2026/10/1〜：1,300円 |
| 交通費 | 1,000円／日 | なし |
| 休憩 | 6時間未満：なし<br>6時間以上8時間未満：45分<br>8時間以上：60分 ※ | 6時間以下：なし<br>6時間超8時間未満：45分<br>8時間以上：60分 |

- 予定の開始〜終了を拘束時間とし、休憩を引いた実働時間 × 勤務日の時給で計算（シフトごとに1円未満切り捨て）
- 交通費は勤務日単位（同じ日に2回入っていても1日分）
- 月は勤務日で集計（締め日ではなくカレンダー月）
- 「勤務済み」と「これから（予定）」を分けて表示
- ※ 千疋屋の8時間以上は指定がなかったため、労働基準法に合わせて60分としています

条件を変えたいときは `calc.js` の `JOBS` を編集してください。

### ② シフト希望入力リマインド（千疋屋のみ）
- 毎月5日・20日以降、提出済みにするまでアプリ上部にバナーを表示
- **Googleカレンダーに登録**：毎月5日・20日の繰り返し予定（通知付き）を作成。スマホのカレンダー通知で確実に届きます
- **.ics ダウンロード**：iPhone の標準カレンダー等に同じ繰り返しリマインドを追加
- **アプリ通知**：5日・20日にアプリを開いたとき通知を表示

> Web アプリはサーバーなしでは決まった時刻に通知を送れないため、確実な通知にはカレンダー登録を使っています。

## 初回設定（Google カレンダー連携）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」で **Google Calendar API** を有効化
3. 「OAuth 同意画面」を作成（ユーザーの種類：外部、テストユーザーに自分の Gmail を追加）
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - 種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：アプリを公開する URL のオリジン（例：`https://nkurea.github.io`）
5. 発行されたクライアント ID をアプリの「設定」に貼り付けて「保存して同期」

使用する権限：予定の読み取り（`calendar.events.readonly`）。リマインドを Googleカレンダーに登録するときだけ書き込み権限（`calendar.events`）を求めます。

## 公開方法
GitHub Pages を有効にすると `https://nkurea.github.io/Beaute-raffinee/baito/` で開けます。
スマホで開き、Safari なら「共有 → ホーム画面に追加」、Chrome なら「ホーム画面に追加」でアプリとして使えます。
